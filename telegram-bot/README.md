# Telegram-бот EFIM FARM TECHNOLOGIES (Cloudflare)

Перенос бота v4.3 (Python/aiogram, работал на компьютере) в Cloudflare Workers:
работает круглосуточно и бесплатно, компьютер не нужен.

- `worker.js` — логика бота и приём заявок с сайта
- `texts.js` — все тексты на трёх языках, каталог, подбор, ссылки, фото (бывший `texts.py`)
- `xlsx.js` — выгрузка заявок в Excel (кнопка «📥 Заявки в Excel» у админа, команда `/excel`)

Воркер в Cloudflare называется **efim-leads**, адрес `https://efim-leads.efimfarm.workers.dev`.

## Что умеет
Всё, что было в v4.3: язык, каталог, о компании, производство, проекты, отделы, контакты,
подбор оборудования, заявка на КП с фото/файлом, меню сотрудника, «Беру в работу» / «Закрыть»,
приглашения сотрудников, команда, рассылка, напоминания о заявках без ответа.

Новое:
- заявки с сайта приходят в бота как обычные заявки (с номером и кнопками);
- путь заявки: 🆕 Новая → 📄 КП отправлено → ✅ Сделка / ❌ Отказ (шаг «Беру в работу» выключен, `TAKE_STEP` в worker.js);
- «📄 Отправить КП»: сотрудник присылает файл/фото/текст — бот пересылает клиенту с подписью на его языке
  (для заявок с сайта — «КП отправлено (вручную)» и кнопка «💬 WhatsApp клиенту»);
- сообщения клиента боту приходят менеджеру его заявки; ответ свайпом «Ответить» уходит клиенту;
- выгрузка всех заявок в Excel (админы);
- «📋 Мои заявки» для клиента (кнопка в меню и /myleads): статус каждой заявки на его языке.

## Настройки (Cloudflare → efim-leads → Settings → Variables and Secrets)
Секреты: `TELEGRAM_BOT_TOKEN`, `TG_WEBHOOK_SECRET`, `SETUP_KEY`.
Переменные: `ADMIN_IDS` (папа), `ADMIN_USERNAMES`, `STAFF_IDS`, `REMIND_MINUTES`.
Сотрудников удобнее добавлять через бота: «Пригласить сотрудника» или `/invite`.

## Служебные адреса (нужен SETUP_KEY)
- `/setup?key=…` — подключить бота к Cloudflare (вебхук + меню команд)
- `/teardown?key=…` — отключить (например, чтобы снова запустить бота на компьютере)
- `/export?key=…` — выгрузить данные (резервная копия)
- `POST /import?key=…` — загрузить данные: `{"users":{…},"admins":[…],"staff":{…},"leads":{…}}`
  (формат как у users.json / admins.json / staff.json / leads.json старого бота)

## Данные
Хранятся в Durable Object `BotState` (SQLite в Cloudflare). Расписание каждую минуту:
напоминания и рассылка (порциями по 40 сообщений).
