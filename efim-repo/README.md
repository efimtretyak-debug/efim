# Тема EFIM Farm Technologies

## Установка
1. WordPress → Внешний вид → Темы → Добавить → Загрузить тему → выберите `efim-theme.zip` → Активировать.
2. При первой активации автоматически создаются: 8 позиций собственного производства, 7 брендов (Faresin, Dairymaster, Kraiburg, Eisele, Dinamica Generale, Urban, MWS) и страница «О компании».
3. Настройки → Постоянные ссылки → нажмите «Сохранить» (обновит адреса страниц).
4. Настройки → Чтение → «Главная страница» → «Ваши последние записи» (дизайн главной задаёт тема).

## Как менять
- Телефон, почта, адрес, соцсети, заголовок и фото на главной: Внешний вид → Настроить → «EFIM: главная и контакты».
- Оборудование: раздел «Оборудование» (название, краткое описание, фото, текст). Тип «Собственное производство» или «Дилерское», бренд — в правой колонке.
- Бренды: Оборудование → Бренды (описание бренда показывается на главной).
- Проекты: раздел «Проекты».
- Заявки: раздел «Заявки» (плюс письмо на почту из настроек).
- Меню: Внешний вид → Меню (пока меню не создано, показывается стандартное).
- Логотип: Внешний вид → Настроить → Айдентика сайта.

## Telegram-бот (позже)
Каждая заявка вызывает хук `efim_new_lead`. Бот подключается так (в плагине или в `functions.php`):

```php
add_action( 'efim_new_lead', function ( $lead ) {
	$token = 'BOT_TOKEN'; $chat = 'CHAT_ID';
	wp_remote_post( "https://api.telegram.org/bot$token/sendMessage", array(
		'body' => array( 'chat_id' => $chat, 'text' => "Новая заявка\n" . $lead['text'] ),
	) );
} );
```
